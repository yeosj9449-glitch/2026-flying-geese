> 이 클라우드 세션은 브라우저를 열 수 없고, 네트워크 정책 때문에 enviagro.go.kr과 농장 사이트에도 접속할 수 없습니다.

**붙여넣을 프롬프트:**

저장소 `yeosj9449-glitch/2026-flying-geese`의 브랜치 `claude/inspiring-allen-h3q1x3`을 받아 주세요.
기획 문서는 `docs/premium_kids_strategy.md`, 공급처 리스트는 `data/sourcing/leads.seed.csv`(30곳), 연락 메시지는 `docs/contact_messages.md`입니다.
`cp data/sourcing/leads.seed.csv data/sourcing/leads.csv` 한 뒤 내장 브라우저로 저와 함께 아래를 진행해 주세요.
로그인이나 본인 인증이 필요한 화면은 제가 직접 입력할 테니 그 단계에서 멈춰 주세요.

1. **인증 조회.** https://www.enviagro.go.kr/portal/info/info_certifi_ok.do 에서 인증번호 18100160, 16303710, 14100057, 14304577, 15102229를 조회합니다.
   생산자명, 인증종류, 품목, 인증기간을 읽어 `leads.csv`의 해당 행(L014, L026, L005, L006, L008)에 `인증조회일`(오늘)과 `인증유효기간`을 채웁니다. 생산자명이 다르면 메모에 적습니다.
   L026(고령 딸기)은 조회 결과로 생산자를 확인해서 `공급처명`을 바꿉니다.
2. **연락처 수집.** `leads.csv` 메모에 있는 URL을 열어 사이트 하단 사업자 정보(상호, 대표자, 전화, 이메일, 카카오톡 채널)와 판매 페이지의 인증번호를 `연락처`/`이메일`/`인증번호` 칸에 채웁니다. 찾지 못한 값은 비워 둡니다(추측 금지).
   새로 찾은 인증번호도 1번처럼 조회합니다.
3. **네이버 검색광고 키워드.** 제가 searchad.naver.com에 로그인하면 도구 → 키워드 도구에서 힌트 키워드 `유기농감귤, 아기귤, 이유식단호박, 아기사과, 돌답례품과일`로 조회하고 CSV를 내려받습니다(5개씩 여러 번: 이유식당근, 아기고구마, 유기농딸기, 유아과일정기배송, 출산선물과일 등).
   내려받은 파일로 `python -m flying_geese.cli keywords --from-file <파일>`을 실행하고 A 등급 결과를 보여 주세요.
4. `python -m flying_geese.cli sourcing`으로 대시보드를 다시 만들고, 바뀐 등급과 다음 할 일을 요약해 주세요.
   `leads.csv`는 개인정보라 커밋하지 않습니다. 코드나 문서를 바꿨을 때만 커밋합니다.
