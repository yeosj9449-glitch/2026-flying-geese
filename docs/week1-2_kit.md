# 1~2주차 실행 키트 (10/20 ~ 11/2)

> [기획안 v2](premium_kids_strategy.md) 8장 로드맵의 1~2주차를 바로 실행하기 위한 체크리스트, 스크립트, 템플릿 모음입니다.
> 진행 상황은 도구로 관리합니다: `python -m flying_geese.cli sourcing` / `sourcing-log` / `keywords` / `influencers`

## 1주차 체크리스트 (10/20~10/26)

### A. 사업 기반 (1~2일)
- [ ] 사업자등록 업태·종목 확인: 도소매 / 전자상거래 소매업 (기존 사업자면 종목 추가)
- [ ] 통신판매업 신고 (정부24), 구매안전서비스 이용확인증 (스마트스토어에서 발급)
- [ ] 스마트스토어 판매자 가입 (심사 기간을 고려해 **오늘 신청**)
- [ ] 브랜드명 후보 3개를 정해 **KIPRIS(kipris.or.kr) 상표 검색**: 29류(가공식품), 31류(신선 농산물), 35류(도소매)
- [ ] 인스타그램 계정 핸들 선점, 프로필 문구 확정
- [ ] 축산물(계란·육류)은 초기 제외. 나중에 취급하면 관할 시군구에 영업 신고 대상인지 확인

### B. 소싱 발굴 (리드 30곳 목표)
1. `data/sourcing/leads.example.csv`를 `leads.csv`로 복사합니다 (예시 6행은 지움).
2. 아래 경로로 리드를 찾아 한 줄씩 입력합니다 (`발굴경로` 칸에 기록).

| 경로 | 방법 | 장점 |
|---|---|---|
| **친환경인증관리정보시스템** (enviagro.go.kr) | 인증 정보 조회에서 품목·지역으로 검색 → 인증받은 농가·법인 목록 확보 | ①번 기준을 처음부터 통과하는 리드 |
| 지자체 농특산물 공식 쇼핑몰 | 시군 단위 공식몰의 친환경 카테고리 입점 농가 | 지자체 검증, 연락처 공개 |
| 네이버 스마트스토어 산지 판매자 | "유기농 감귤 산지직송" 같은 검색 → 인증 마크와 인증번호를 표기한 판매자 | 온라인 판매 경험, 택배 출고 가능 |
| 친환경 농업인 단체·작목반 | 지역 친환경농업인연합회, 유기농 작목반 | 여러 농가를 한 번에 소개받음 |
| 로컬푸드 직매장 출하 농가 | 직매장 친환경 코너 생산자 표기 | 소량 다품목 |
| aT 온라인도매시장 / 스마트 APC | 저장소 1단계 연동 데이터 | 물량·가격 안정 |
| 유아식 수산 가공업체 | "HACCP 무염 순살 생선" 검색 | 수산 키즈 카테고리 |
| 맘카페 추천 | "유기농 과일 어디서 사세요" 류 글 | 이미 아이 엄마들이 검증한 곳 |

3. 처음 10곳의 우선순위는 11~12월 판매 품목입니다: **감귤(소과), 부사·미니사과, 고구마, 단호박, 딸기(12월), 순살 생선.**

### C. 컨택 (15곳 목표)
- 아래 스크립트로 연락하고, 매번 기록합니다:
  ```bash
  python -m flying_geese.cli sourcing-log L001 --channel 전화 --summary "입점 제안, 소과 선별 가능" \
      --outcome "샘플 발송 약속" --stage 컨택 --next-action "샘플 수령 확인" --next-date 2026-10-24
  ```
- 매일 아침 `python -m flying_geese.cli sourcing`을 실행해서 지연된 할 일, 재연락 대상, 자동 제안 액션을 확인합니다.

### D. 키워드 1차 발굴
- [ ] 네이버 검색광고 가입 → API 키 발급 (도구 > API 사용 관리) → `.env`에 입력
- [ ] API 키 없이 먼저 하려면: 검색광고 키워드도구 화면에서 힌트 키워드(예: 아기귤, 유기농감귤, 이유식단호박)를 넣고 결과를 CSV로 내려받은 뒤 `python -m flying_geese.cli keywords --from-file 다운로드.csv`
- [ ] 결과의 **C 콘텐츠 키워드**를 인스타·블로그 첫 콘텐츠 10개의 주제로 사용

### E. 인플루언서 리스트 정리
- [ ] 보유 리스트를 `data/marketing/influencers.csv`에 붙여넣기 (`influencers.example.csv`의 열 순서). 최소한 핸들, 팔로워, 평균좋아요, 평균댓글, 아이개월수만 채우면 됩니다
- [ ] `python -m flying_geese.cli influencers` → 우선순위 상위 20명 확정

## 공급처 컨택 스크립트

### 전화 (첫 통화, 3분)
> 안녕하세요, ○○(브랜드명)의 ○○○입니다. 아이 키우는 집을 위해 **유기농·무농약 인증 농산물만 골라서 소개하는 큐레이션 스토어**를 준비하고 있습니다. 친환경인증 정보에서 농장을 보고 연락드렸어요.
>
> 저희는 판매 수량은 많지 않아도, 농장 이야기와 인증 정보를 자세히 소개해서 **제값을 받고 꾸준히 판매하는 방식**입니다. 위탁(주문이 들어오면 농장에서 바로 발송) 방식으로 함께하실 수 있을지 여쭤보고 싶습니다.

**확인할 질문 (입점 기준표 순서대로):**
1. 인증 종류와 인증번호, 유효기간 (→ 통화 후 enviagro에서 직접 조회)
2. 최근 1년 이내 잔류농약 검사성적서 (수산은 중금속·방사능)가 있는지
3. 소과(한입 크기)를 따로 골라 보낼 수 있는지, 1kg 이하 소포장이 가능한지
4. 당도 측정을 하는지, 수확 후 며칠 안에 출고하는지, 냉장 발송이 가능한지
5. **올해 작황과 첫 수확(출하) 예정일, 주당 출하 가능량** (제철 시기 확정용)
6. 위탁 공급가, 택배비, 발송 마감 시간, 송장 회신 방법
7. 농장 사진·인터뷰를 상세페이지에 써도 되는지

### 문자 / 카톡 (통화 전 예고 또는 부재 시)
> [○○ 큐레이션] 안녕하세요, 아이를 위한 유기농 먹거리 큐레이션 스토어 ○○입니다. 친환경인증 농가로 확인하고 연락드렸습니다. 위탁 판매 협업을 제안드리고 싶은데, 편하신 시간에 5분 통화 가능할까요? 감사합니다.

### 이메일 / 제안서 요약
- 제목: [입점 제안] 아이를 위한 유기농 큐레이션 스토어 ○○, 위탁 판매 협업
- 본문: ① 우리 소개(컨셉 한 줄 + 고객: 이유식기 부모) ② 농장을 고른 이유 ③ 위탁 방식(주문→발주서 자동 전달→농장 발송→송장 회신) ④ 기대 효과(제값 판매, 농장 스토리 노출) ⑤ 요청 자료(인증서, 검사성적서, 공급가표, 사진)

## 샘플 검수 체크리스트 (`samples.csv`에 기록)

| 항목 | 확인 방법 | 점수 기준 (1~5) |
|---|---|---|
| 배송일수 | 주문일 → 수령일 | 2일 이내 권장 |
| 당도(Brix) | 당도계 측정 (1만 원대 굴절 당도계) | 수치 그대로 기록 |
| 신선도 | 무름·상처·시든 잎·비린내 | 5 = 흠 없음 / 2 이하 = 불합격 |
| 맛 | 직접 시식 (가능하면 아이도) | 5 = 재구매 의사 확실 |
| 포장 | 완충재, 아이스팩, 파손, 개봉 편의 | 5 = 선물로 보내도 됨 |
| 아이 적합 | 크기, 껍질 까기, 씨, 손질 편의 | 5 = 아이가 혼자 먹기 쉬움 |

**판정:** 평균 4.0 이상이고 2점 이하 항목이 없으면 통과 (도구가 자동으로 판정). 사진은 상세페이지와 SNS에 쓸 수 있도록 함께 찍어 둡니다.

## 상세페이지 구조 (전 상품 공통)

1. **큐레이터 한 줄**: "이번 달 감귤 농가 7곳 중 이 농장을 고른 이유"
2. **검증 배지**: 인증 종류와 인증번호(조회 방법 안내), 검사성적서 요약(검사일, 불검출 항목 수), 키즈 전용 배지(③ 충족 시)
3. **아이 기준**: 크기 사진(아이 손과 비교), 소포장 단위, 손질법
4. **농장 이야기**: 사진 3~5장, 농부 인터뷰 3문장
5. **배송**: 수확 후 산지 직송, 주문 후 2~3일, 냉장 여부
6. **보장 정책**: 맛·품질 불만족 시 재발송
7. **표현 주의**: 효능·질병 표현 금지, "유기농"은 인증번호와 함께

## 인플루언서 템플릿

### 시딩 DM (1차)
> 안녕하세요 @○○님! 아이를 위한 유기농 먹거리 큐레이션 ○○입니다. ○○님이 올려주신 이유식 기록을 보고 연락드려요.
>
> 저희는 **인증번호와 잔류농약 검사성적서를 모두 공개하는 농가**만 골라 소개하는데요, 이번 달 큐레이션인 유기농 소과 감귤을 ○○이와 먼저 맛봐 주실 수 있을까요? 게시는 자유이고, 올려주실 경우에는 '협찬' 표기만 부탁드립니다.
>
> 괜찮으시면 받으실 주소를 알려주세요!

### 리마인드 (발송 7일 후, 미게시 시 1회만)
> ○○님, 감귤은 잘 받으셨을까요? ○○이 입맛에 맞았는지 궁금해요. 혹시 불편하셨던 점이 있으면 편하게 말씀 주세요!

### 공구 제안 (게시 후 반응이 좋은 경우)
> ○○님 게시물에 문의가 많았다고 들었어요. 그래서 **○○님 팔로워분들만을 위한 사전예약 공구**를 제안드리고 싶습니다.
> - 방식: 3~5일 사전예약 → 마감 후 농장에서 일괄 수확·발송 (한정 ○○박스)
> - 판매: 저희 스토어 전용 링크와 쿠폰(○○님 코드), CS와 배송은 저희가 전담
> - 수수료: 판매액의 ○○% (월말 정산)
> - 표기: 게시물에 '광고' 표기 필수
