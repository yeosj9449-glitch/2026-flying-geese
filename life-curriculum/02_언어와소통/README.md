# 2. 🗣️ 언어와 소통 (Language & Communication)

**목표**: 한국어로 깊이 생각하고 쓰며, 영어로 세계와 일하고, 말로 사람을 움직이는 사람.

| 단계 | 성취 기준 | 핵심 활동 |
|---|---|---|
| 🍼 | 옹알이 주고받기, 이름 반응 | **서브앤리턴 대화**, 실황 중계 말하기, 노래·리듬, 그림책(흑백→컬러) |
| 🚶 | 50단어 → 두 단어 문장 → 문장 폭발 | 하루 그림책 3권+, 질문형 읽기(대화식 읽기 Dialogic Reading), 영어 노래·그림책 노출 |
| 🎨 | 이야기 다시 말하기, 음운 인식, 이야기 지어내기 | 책 '함께 만들기', 역할놀이, 한글은 아이가 관심 보일 때 놀이로, 영어는 '습득'(노래·영상 소량·원어민 그림책) |
| 🔤 | 유창한 읽기, 일기 쓰기, 영어 읽기 시작 | 매일 20분+ 독서, 가족 독서 시간, 짧은 발표, 영어 리더스 |
| 🔍 | 논리적 글쓰기(주장-근거), 토론, 영어 독해·쓰기 | 주 1회 에세이, 가족 토론, 영어 소설 챕터북, 제2외국어 맛보기 |
| 🧭 | 설득·서사 글쓰기, 프레젠테이션, 영어 실전 | 블로그/뉴스레터 운영, 모의 유엔·토론대회, 영어로 프로젝트 |
| 🚀 | 연구형 글쓰기, 협상, 공적 말하기 | IB Extended Essay 수준 4,000단어 소논문, 인터뷰·팟캐스트 제작 |

**원칙**
- 이중언어: 부모 한 명이 원어민 수준이 아니라면 **억지로 영어로 대화하지 않는다.** 모국어 깊이가 제2언어 실력의 토대(Cummins의 상호의존 가설).
- AI 번역 시대에도 영어는 *사람과 직접 연결되는 도구*로서 필수. 3세 이후 '습득' 환경, 7세 이후 '학습' 병행.

단계 표기: 🍼0세 · 🚶1–2세 · 🎨3–6세 · 🔤7–9세 · 🔍10–12세 · 🧭13–15세 · 🚀16–18세

## 🌏 이중언어 전략 (부모 언어: 한국어 / 해외 거주 가능성)

### 원칙: "집 언어는 한국어, 영어는 환경으로" (Minority Language at Home)
- 부모가 원어민이 아닌 언어로 대화하면 **말의 양과 질(어휘·감정·이야기)이 떨어집니다.** 0~6세 언어 발달의 핵심은 양질의 대화량이므로, 부모는 **가장 풍부하게 말할 수 있는 한국어**로.
- 모국어가 깊을수록 제2언어 학업 능력도 잘 자랍니다 (Cummins의 상호의존 가설).
- 해외로 이주하면 영어(현지어)는 학교·친구로 빠르게 늘고, 오히려 **한국어가 빠르게 약해집니다** → 한국어 유지가 장기 과제.

### 단계별 계획
| 단계 | 한국에 있을 때 | 해외 이주 후 |
|---|---|---|
| 🍼🚶 0~2세 | 한국어 대화·그림책 중심. 영어는 동요·영어 그림책 소리 내 읽기(부모 발음 걱정 X) 소량 | 집에서는 100% 한국어. 현지어는 놀이터·도서관 스토리타임 |
| 🎨 3~6세 | 영어 그림책 매일 1권, 영어 노래, 양질 영상 소량(함께 시청), 가능하면 영어 놀이 환경(놀이 모임·기관) | 집 한국어 유지 + 한글 놀이. 현지 기관에서 현지어 습득. 침묵기 정상 |
| 🔤 7~9세 | 영어 읽기(파닉스 → 리더스), 화상 대화 수업 검토 | 주말 한글학교, 한국어 책 매일, 한국 가족과 화상통화 |
| 🔍 10세+ | 영어 챕터북·글쓰기, 제3언어 맛보기 | 한국어 읽기·쓰기 유지(한국 뉴스·책 토론), 한국 방문 시 캠프 |

### 체크포인트
- ✅ 두 언어의 **합친 어휘**로 발달을 평가 (이중언어 아동은 한 언어만 보면 늦어 보일 수 있음 — 정상)
- ✅ 언어 섞어 쓰기(코드 스위칭)는 정상적인 이중언어 발달
- ⚠️ 두 언어 모두에서 발달이 늦으면 전문가 상담
