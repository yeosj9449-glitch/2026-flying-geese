# 01. 9대 교과목 상세

각 과목은 **[목표] → [단계별 성취 기준] → [핵심 활동/도구] → [부모 체크포인트]** 순으로 정리합니다.
단계 표기: 🍼0세 · 🚶1–2세 · 🎨3–6세 · 🔤7–9세 · 🔍10–12세 · 🧭13–15세 · 🚀16–18세

---

## 1. 🏃 몸과 뇌 (Physical & Brain Literacy)

**목표**: 평생 운동을 즐기고, 수면·영양·주의력을 스스로 관리하는 사람.

| 단계 | 성취 기준 | 핵심 활동 |
|---|---|---|
| 🍼 | 터미타임, 뒤집기·기기, 수면 리듬 형성 | 하루 여러 번 엎드려 놀기(WHO 권장: 깨어 있을 때 하루 30분 이상 누적), 바닥 자유 놀이 |
| 🚶 | 걷기·오르기·던지기, 혼자 먹기 | 놀이터·공원 매일, 계단, 공놀이, 자기 숟가락 |
| 🎨 | 기초 운동기술(달리기·점프·균형·잡기), 수영 입문, 자전거 | 하루 3시간 이상 신체활동(WHO 3–4세 기준), 매일 바깥놀이 |
| 🔤 | 팀 스포츠 1개 + 개인 스포츠 1개, 수영 생존 수영 | 태권도/축구/수영 등, 주말 가족 하이킹 |
| 🔍 | 체력 기초, 수면·영양의 '이유' 이해 | 몸 일기(수면·기분·에너지 기록), 요리 주 1회 |
| 🧭 | 주의력 관리, 스마트폰과 수면 관계 이해 | 디지털 디톡스 실험, 근력운동 입문 |
| 🚀 | 스스로 루틴 설계, 스트레스 관리 | 자기 건강 대시보드, 명상/호흡법, 평생 운동 1개 확정 |

**부모 체크포인트**: 수면(연령별 권장 시간) 확보가 최우선. 수면이 무너지면 다른 모든 과목을 멈추고 수면부터.

## 2. 🗣️ 언어와 소통 (Language & Communication)

**목표**: 한국어로 깊이 생각하고 쓰며, 영어로 세계와 일하고, 말로 사람을 움직이는 사람.

| 단계 | 성취 기준 | 핵심 활동 |
|---|---|---|
| 🍼 | 옹알이 주고받기, 이름 반응 | **서브앤리턴 대화**, 실황 중계 말하기, 노래·리듬, 그림책(흑백→컬러) |
| 🚶 | 50단어 → 두 단어 문장 → 문장 폭발 | 하루 그림책 3권+, 질문형 읽기(대화식 읽기 Dialogic Reading), 영어 노래·그림책 노출 |
| 🎨 | 이야기 다시 말하기, 음운 인식, 이야기 지어내기 | 책 '함께 만들기', 역할놀이, 한글은 아이가 관심 보일 때 놀이로, 영어는 '습득'(노래·영상 소량·원어민 그림책) |
| 🔤 | 유창한 읽기, 일기 쓰기, 영어 읽기 시작 | 매일 20분+ 독서, 가족 독서 시간, 짧은 발표, 영어 리더스 |
| 🔍 | 논리적 글쓰기(주장-근거), 토론, 영어 독해·쓰기 | 주 1회 에세이, 가족 토론, 영어 소설 챕터북, 제2외국어 맛보기 |
| 🧭 | 설득·서사 글쓰기, 프레젠테이션, 영어 실전 | 블로그/뉴스레터 운영, 모의 유엔·토론대회, 영어로 프로젝트 |
| 🚀 | 연구형 글쓰기, 협상, 공적 말하기 | IB Extended Essay 수준 4,000단어 소논문, 인터뷰·팟캐스트 제작 |

**원칙**
- 이중언어: 부모 한 명이 원어민 수준이 아니라면 **억지로 영어로 대화하지 않는다.** 모국어 깊이가 제2언어 실력의 토대(Cummins의 상호의존 가설).
- AI 번역 시대에도 영어는 *사람과 직접 연결되는 도구*로서 필수. 3세 이후 '습득' 환경, 7세 이후 '학습' 병행.

## 3. 🔢 수학적 사고 (Mathematical Thinking)

**목표**: 계산 기계가 아니라, 패턴을 보고 문제를 모델링하며 숫자에 속지 않는 사람.

| 단계 | 성취 기준 | 핵심 활동 |
|---|---|---|
| 🍼🚶 | 크다/작다, 많다/적다, 모양 | 블록, 쌓기, 넣고 빼기, 일상 속 '수 말하기' |
| 🎨 | 수감각(1~20), 수 분해(5=2+3), 패턴, 공간감각 | 보드게임(주사위·윷놀이·뱀사다리), 칠교·블록, 요리 계량, 손가락 수 |
| 🔤 | 사칙연산 이해(CPA), 자릿값, 측정, 분수 감각 | 싱가포르 수학 방식(구체물→그림(바 모델)→기호), 용돈 계산 |
| 🔍 | 분수·비율·음수, 문제해결 전략, 확률 감각 | 수학 퍼즐, 수학 일기("왜 그렇게 풀었나"), 데이터 수집 프로젝트 |
| 🧭 | 대수·함수·기하 증명, **통계 리터러시** | 뉴스 속 그래프 비판하기, 스프레드시트, 수학 경시는 '즐거우면' |
| 🚀 | 미적분·확률통계·선형대수 기초, 수학적 모델링 | 실제 데이터 분석 프로젝트, Python으로 시뮬레이션 |

**원칙**: 7세 전 연산 학습지 반복보다 **수감각·공간감각·보드게임**이 장기 성취를 더 잘 예측. 속도보다 이해.

## 4. 🔬 과학적 탐구와 자연 (Scientific Inquiry & Nature)

**목표**: "어떻게 알 수 있지?"를 습관처럼 묻고, 증거로 생각을 바꿀 줄 아는 사람.

| 단계 | 성취 기준 | 핵심 활동 |
|---|---|---|
| 🍼🚶 | 감각 탐색, 원인-결과 발견 | 다양한 질감·소리·물놀이, 떨어뜨리기 실험(!) |
| 🎨 | 관찰·분류·예측 | 숲 놀이, 곤충·식물 키우기, "왜 그럴까?" 함께 추측하기, 부엌 실험 |
| 🔤 | 공정한 실험(변수 하나만 바꾸기), 기록 | 과학 노트, 자연 관찰 일지, 과학관 정기 방문 |
| 🔍 | 가설-실험-결론, 지구·우주·생명 큰 그림 | **빅히스토리(Big History)**, 과학 프로젝트 대회, 망원경·현미경 |
| 🧭 | 과학적 방법의 한계, 가짜 과학 판별 | 과학 뉴스 팩트체크, 연구 논문 초록 읽기 |
| 🚀 | 독립 연구, 기후·바이오·에너지 등 미래 이슈 | 시민과학 프로젝트 참여, 소논문 |

## 5. 🤖 디지털·AI 리터러시 (Digital & AI Literacy)

**목표**: AI와 기술을 **비판적으로 이해하고, 창조적으로 지휘하며, 윤리적으로 쓰는** 사람.
(UNESCO 학생용 AI 역량 4영역: 인간 중심 사고 · AI 윤리 · AI 기술과 응용 · AI 시스템 설계)

| 단계 | 성취 기준 | 핵심 활동 |
|---|---|---|
| 🍼 | (스크린 없음 — 영상통화만 예외) | 부모가 아기 앞에서 폰 사용 줄이기 |
| 🚶 | (스크린 최소화) | 2세 전 스크린은 영상통화 외 지양, 시청 시 반드시 함께 |
| 🎨 | **언플러그드 컴퓨팅 사고**: 순서, 반복, 조건 | 로봇 놀이("엄마 로봇에게 명령하기"), 패턴 블록, 코딩 보드게임. 스크린은 하루 1시간 이내, 양질 콘텐츠를 함께 |
| 🔤 | 블록 코딩, 인터넷 안전, 광고 구분 | ScratchJr → Scratch, "이 영상은 누가 왜 만들었을까?" |
| 🔍 | AI가 어떻게 배우는지 이해, AI와 함께 만들기 | Teachable Machine 등으로 AI 직접 학습시키기, AI 답의 오류 찾기 게임, 기초 Python |
| 🧭 | 텍스트 코딩, 데이터·알고리즘 편향, 개인정보 | Python 프로젝트, AI 에이전트로 작은 자동화, 딥페이크 판별 |
| 🚀 | AI로 실제 문제 해결, 기술 윤리 판단 | AI 활용 창업/연구 프로젝트, 오픈소스 기여, 기술 정책 토론 |

**AI 시대 핵심 원칙**
- **"먼저 스스로 생각 → 그다음 AI → 다시 내 판단"** 순서를 습관화 (AI에 사고를 위탁하지 않기)
- AI 결과물은 항상 *검증 대상*. 출처 확인, 교차 검증.
- 기본기(읽기·쓰기·수학)는 AI 이전에 손으로 익힌다.

## 6. 💛 마음과 관계 (Social-Emotional Learning)

**목표**: 자기 감정을 알고 다스리며, 타인을 이해하고 함께 일할 수 있는 사람. (CASEL 5대 역량)

| 단계 | 성취 기준 | 핵심 활동 |
|---|---|---|
| 🍼 | **안정 애착** | 즉각적·일관된 반응, 스킨십, 눈맞춤 |
| 🚶 | 감정 단어 시작, 기다리기 연습 | 감정 이름 붙여주기("속상했구나"), 예측 가능한 루틴 |
| 🎨 | 감정 조절 전략, 나누기·차례, 공감 | **감정 코칭(가트맨 5단계)**, 감정 카드, 진정 코너, 역할놀이 |
| 🔤 | 친구 관계 문제 해결, 성장 마인드셋 | 가족 회의, "실패 자랑 시간", 갈등 해결 대본 |
| 🔍 | 관점 취하기, 협업, 리더십 | 팀 프로젝트, 봉사활동, 형제·친구 멘토링 |
| 🧭 | 정체성, 사춘기 감정, 건강한 관계·경계 | 일기, 1:1 부모 데이트, 비폭력대화(NVC) |
| 🚀 | 회복탄력성, 진로 가치관, 조직 내 협업 | 인턴/아르바이트, 실패 회고, 멘토 찾기 |

## 7. 🧠 사고의 기술 (Thinking Skills & Metacognition)

**목표**: 좋은 질문을 하고, 근거로 판단하며, 자기 생각을 생각할 줄 아는 사람.

| 단계 | 성취 기준 | 핵심 활동 |
|---|---|---|
| 🎨 | 질문하기, "왜?" 존중, 실행기능 기초(작업기억·억제·유연성) | "가라사대 게임", 얼음땡, 숨은그림찾기, 질문 노트(부모가 기록) |
| 🔤 | 근거 말하기, 사고 루틴 | **Visible Thinking**: See-Think-Wonder, "무엇이 그렇게 생각하게 했어?" |
| 🔍 | 어린이 철학(P4C), 논리 오류 구별 | 그림책·동화로 철학 토론, 논리 퍼즐, 체스 |
| 🧭 | 비판적·창의적 사고, 인지 편향 | **지식론(TOK) 맛보기**: "역사/과학/예술에서 '안다'는 건?", 인지 편향 카드 |
| 🚀 | 시스템 사고, 의사결정 프레임, 학습법 | Minerva식 사고 습관, 2차 효과 사고, 사전 부검(pre-mortem), 학습 과학(인출·간격 반복) |

## 8. 🎨 창조와 표현 (Creativity & Expression)

**목표**: 생각을 형태로 만들고, 아름다움을 느끼며, 문제를 창의적으로 푸는 사람.

| 단계 | 성취 기준 | 핵심 활동 |
|---|---|---|
| 🍼🚶 | 감각 경험, 리듬 | 노래, 악기 흔들기, 끄적이기, 촉감 놀이 |
| 🎨 | 자유 표현, 만들기 | 열린 재료(점토·종이·블록·자연물), 레고, 춤, 노래, 미술관 나들이 |
| 🔤 | 악기 1개 입문, 그리기·만들기 기술 | 피아노/바이올린 등, 메이커 활동, 연극 |
| 🔍 | 디자인 씽킹 입문 | "가족 불편 해결 프로젝트", 스톱모션, 작품 전시회 |
| 🧭 | 매체 선택·작품 포트폴리오 | 디지털 아트·영상·음악 제작, 해커톤 |
| 🚀 | 자기 표현 장르 심화, 창작물 공개 | 개인 작품집, 공모전, 크리에이터 활동 |

## 9. 🌍 세상과 돈 (World, History & Money)

**목표**: 세상의 작동 원리(역사·문화·경제)를 알고, 돈을 다룰 줄 알며, 스스로 기회를 만드는 사람.

| 단계 | 성취 기준 | 핵심 활동 |
|---|---|---|
| 🎨 | 가족·이웃·직업, '돈은 교환 수단' | 시장놀이, 동전 분류, 저금통 3개(쓰기·모으기·나누기) |
| 🔤 | 용돈 관리, 지도·세계 문화 | 주간 용돈 시작, 세계지도·지구본, 세계 음식의 날, 가족 여행 기획 참여 |
| 🔍 | 역사 큰 흐름, 저축·이자·기회비용, 작은 장사 | 한국사·세계사 이야기, **레모네이드 스탠드식 첫 판매**, 은행 계좌 |
| 🧭 | 투자·복리·리스크, 경제 뉴스, 세계시민 | 모의 투자, 가계부 참여, 국제 이슈 토론, 해외 교류 |
| 🚀 | 실전 창업/프로젝트, 세금·계약 기초, 진로 설계 | 작은 사업 운영, 실제 소액 투자, 인턴십, 갭이어 고민 |

## 관통 축: 자기주도성과 성품

| 단계 | 자기주도 단계 |
|---|---|
| 🎨 | 선택지 2개 중 고르기 → 스스로 정리 |
| 🔤 | 주간 계획 함께 세우기, 집안일 책임 1개 |
| 🔍 | 스스로 학습 계획 + 부모 점검 |
| 🧭 | 자기 프로젝트 1개를 처음부터 끝까지 |
| 🚀 | 부모는 '코치', 아이가 '감독' |

**성품 키워드 (IB 학습자상에서 우리 집 버전 선택)**: 탐구하는 · 정직한 · 배려하는 · 도전하는 · 성찰하는
