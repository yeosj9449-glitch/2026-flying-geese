# 02. 단계별 로드맵 (0~18세)

각 단계마다 **"이 시기에 꼭 잡아야 할 3가지"**만 기억하세요. 나머지는 보너스입니다.

---

## 🍼 0세 (2026) — 애착·감각기
**꼭 잡을 3가지**: ① 안정 애착 ② 언어 샤워(서브앤리턴) ③ 수면·몸 움직임
- 교재는 필요 없음. **부모의 얼굴·목소리·반응**이 커리큘럼 전부.
- 상세: [`11_월령별_실행플랜/0세`](../11_월령별_실행플랜/0세_2026-04_2027-03.md)

## 🚶 1~2세 (2027~2028) — 탐색·언어 폭발기
**꼭 잡을 3가지**: ① 언어(그림책 매일) ② 자율성(스스로 하기) ③ 감정 이름 붙이기
- 몬테소리식 실생활: 컵 옮기기, 옷 고르기, 정리함 넣기
- 스크린: 영상통화 외 지양 (2세 전후로 매우 제한적·함께 시청)
- 하루 구성 예: 바깥놀이 2시간+ · 책 30분+ · 자유놀이 · 낮잠

## 🎨 3~6세 (2029~2032) — 놀이·상상기
**꼭 잡을 3가지**: ① 실행기능(기다리기·규칙 놀이) ② 풍부한 언어·이야기 ③ 수감각·자연 탐구
| 영역 | 주당 권장 (가정) |
|---|---|
| 자유놀이·바깥놀이 | 매일 2~3시간 |
| 그림책·이야기 | 매일 30~45분 |
| 보드게임·수 놀이 | 주 3~4회 × 20분 |
| 자연·과학 탐구 | 주 2회 (숲·공원·부엌 실험) |
| 미술·음악·몸 표현 | 주 3회 |
| 영어 습득 환경 | 매일 15~30분 (노래·그림책·대화) |
| 언플러그드 코딩 | 주 1회 놀이 |
- ❌ 지양: 연산 학습지 과다, 조기 문자 강요, 장시간 학원
- ✅ 핀란드 원칙: 7세 전엔 '놀이를 통한 학습'

## 🔤 7~9세 (2033~2035, 초1~3) — 기초 도구 습득기
**꼭 잡을 3가지**: ① 독서 습관(평생) ② 수학 이해(CPA) ③ 운동·악기 '하나씩 꾸준히'
| 영역 | 주당 권장 |
|---|---|
| 독서 | 매일 20~40분 |
| 수학 (개념+게임) | 주 4회 × 20~30분 |
| 영어 (리더스·노래·대화) | 주 4~5회 × 20분 |
| 과학 노트·자연 관찰 | 주 1~2회 |
| 운동 | 주 3회+ |
| 악기 | 주 3~5회 × 15~20분 |
| 가족 회의 + 용돈 | 주 1회 |
| 블록 코딩 | 주 1회 |

## 🔍 10~12세 (2036~2038, 초4~6) — 탐구·프로젝트기
**꼭 잡을 3가지**: ① 글쓰기(주장+근거) ② 학기당 프로젝트 1개 (현상기반학습) ③ AI·코딩 직접 만들기
- 프로젝트 예시: "우리 동네 쓰레기 문제", "가족 여행 예산 짜기", "AI로 새 분류기 만들기", "작은 장사 해보기"
- 철학 토론, 빅히스토리, 첫 판매 경험

## 🧭 13~15세 (2039~2041, 중) — 정체성·전문성 탐색기
**꼭 잡을 3가지**: ① 자기 프로젝트 끝까지(블로그·앱·작품·사업) ② 비판적 사고(TOK·통계·미디어) ③ 건강한 관계와 정체성
- 부모 역할: 교사 → **코치**로 전환. 1:1 대화 시간 주 1회 확보.
- 디지털: 스마트폰 도입 시 가족 미디어 계약서 작성

## 🚀 16~18세 (2042~2044, 고) — 자기주도·실전기
**꼭 잡을 3가지**: ① 소논문/심화 연구 ② 실전 경험(인턴·창업·봉사) ③ 진로 가치관과 의사결정
- IB DP 구조 차용: 지식론(TOK) + 소논문(EE) + CAS(창의·활동·봉사)
- 국내 입시와 병행한다면, 이 3요소는 학생부 세특·탐구활동으로 자연스럽게 연결됨

## 학년별 '세계 이벤트' 연동 아이디어
- 매년 **가족 연간 테마** 1개 (예: 2030 바다, 2031 우주, 2032 음식과 세계 …)
- 매년 **가족 여행 1회는 아이가 기획에 참여** (나이에 맞게: 고르기 → 일정 → 예산 → 전부)
