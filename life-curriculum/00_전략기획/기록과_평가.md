# 05. 기록과 평가

시험 점수가 아니라 **관찰 → 포트폴리오 → 성찰**로 평가합니다. (IB·레지오 에밀리아의 '기록화 Documentation' 방식)

---

## 1. 기록 3종 세트
| 기록 | 주기 | 방법 |
|---|---|---|
| 📸 관찰 일지 | 주 1회 | 사진 1~3장 + 짧은 메모 (아래 템플릿) |
| 🗂️ 포트폴리오 | 분기 1회 | 대표 작품·말·질문 선별 보관 (7세 이후엔 아이가 직접 고름) |
| 🔁 분기 리뷰 | 3개월마다 | 9대 과목 신호등 체크 + 다음 분기 포커스 3개 |

## 2. 분기 리뷰 템플릿
```
## 20XX년 Q_ 리뷰 (만 _세 _개월)

### 9대 과목 신호등 (🟢 잘 되고 있음 / 🟡 보통 / 🔴 신경 써야 함)
- 🏃 몸과 뇌:
- 🗣️ 언어와 소통:
- 🔢 수학적 사고:
- 🔬 과학적 탐구:
- 🤖 디지털·AI:
- 💛 마음과 관계:
- 🧠 사고의 기술:
- 🎨 창조와 표현:
- 🌍 세상과 돈:

### 이번 분기 아이가 한 가장 인상 깊은 질문/말:
### 아이가 가장 몰입한 것:
### 힘들었던 것:
### 다음 분기 포커스 3가지:
1.
2.
3.
### 커리큘럼 수정 사항 (→ CHANGELOG 반영):
```

## 3. 발달 체크
- 영유아 국가건강검진(생후 14일~71개월, 총 8회) 결과를 함께 기록
- 걱정되는 신호가 있으면 커리큘럼보다 **전문가 상담이 우선**
