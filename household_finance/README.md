# 🏠 우리집 주식회사 — 가정 자산관리 대시보드 (MVP)

가정을 기업처럼 운영하기 위한 자산관리 스프레드시트와 자동화 도구입니다.
재무상태표 · 손익계산서 · 현금흐름 · 예산 · 투자 · 부채 · 목표 · 보험을 하나의 대시보드로 묶었습니다.

- **1단계**: 스프레드시트 MVP (엑셀 / 구글 시트) + 파이썬 자동화 도구
- **2단계 (현재)**: 같은 데이터·같은 계산을 쓰는 웹앱. 부부 각자 로그인, 브라우저에서 분류·업로드·결산 ([아래](#2단계-웹앱))

## 바로 쓰기

| 파일 | 용도 |
| --- | --- |
| `templates/우리집_자산관리_템플릿.xlsx` | **실제 사용용 빈 템플릿**. 카테고리·분류규칙·목표치 기본값만 들어 있음 |
| `templates/우리집_자산관리_샘플.xlsx` | 가상의 맞벌이 3인 가구 12개월치 샘플. 입력 형식과 대시보드 동작 확인용 |

엑셀에서 바로 열거나, 구글 드라이브에 올린 뒤 **구글 시트로 열기**를 하면 됩니다. 부부가 함께 보려면 구글 시트 공유가 가장 간편합니다.

### 처음 시작 (1회, 약 1시간)
1. **계좌**: 가족의 모든 계좌·자산·부채 등록 (유형, 소유자, 유동성)
2. **스냅샷**: 지난달 말 기준 계좌별 잔액 입력 → 순자산·재무상태표가 바로 계산됨
3. **예산**: 카테고리별 월 예산(비정기비는 연 예산)을 부부가 함께 확정
4. **투자·부채·목표·보험·일정** 입력
5. **설정**: 목표 저축률, 비상자금 개월수, 구성원별 월 투자 납입 목표 확인

### 색 규칙
파란 글씨 = 직접 입력 · 검정 글씨 = 수식(수정 금지) · 노란 칸 = 핵심 설정값

## 시트 구성 (17개)

| 구분 | 시트 | 기업 비유 | 내용 |
| --- | --- | --- | --- |
| 요약 | 대시보드 | 경영 대시보드 | KPI 10개, 알림 11종, 구성원별 순자산, 목표 진척, 차트 4종 |
| 입력 | 거래내역 | 분개장 | 일자·내용·금액·카테고리·구성원 (월/대분류/필수는 자동) |
| 입력 | 스냅샷 | 월말 결산 | 매월 말 계좌별 잔액 |
| 입력 | 계좌 | 계정과목표 | 유형(현금성/투자/연금/부동산/기타자산/부채)·소유자·유동성 |
| 입력 | 투자 | 포트폴리오 | 보유종목 → 자산배분·리밸런싱, 투자금 확대 트래킹, 절세계좌 한도 |
| 입력 | 부채 | 차입금 관리 | 금리·만기·원리금, DSR, 금리 +1%p 시뮬레이션, 상환 우선순위 |
| 입력 | 목표 | 중장기 사업계획 | 목표금액·기간·연결계좌 → 진척률, 계획 대비 순항/지연, 필요 월적립 |
| 입력 | 보험 | 리스크 관리 | 구성원 × 보장항목 매트릭스로 보장 공백 자동 탐지 |
| 입력 | 일정 | 자금 일정표 | 만기·세금·명절·보너스 → 현금흐름 예측과 D-day 알림 |
| 입력 | 예산 | 예산 통제 | 월/연 예산 대비 실적, 구성원별 실적 |
| 보고 | 손익 | 손익계산서 | 최근 12개월, 저축률·고정비 비율·투자 납입률 |
| 보고 | 재무상태표 | 재무상태표 | 유형·유동성·구성원별 자산/부채, 12개월 추이, 계좌별 잔액 |
| 보고 | 현금흐름 | 자금수지 계획 | 향후 6개월 예상 잔고, 최소잔고 미달 경고 |
| 기준 | 설정 · 카테고리 · 분류규칙 | 경영 목표·회계 기준 | KPI 목표치, 카테고리 체계, 자동 분류 키워드 |

## 핵심 KPI

| KPI | 계산식 | 기본 목표 |
| --- | --- | --- |
| 순자산 | 총자산 − 총부채 | 전월 대비 증가 |
| 저축률 | (소득 − 소비지출) ÷ 소득 | 30% 이상 |
| **월 투자 납입액** | 투자이체 + 연금납입 | 구성원별 목표 합 (기본 220만 원) |
| 투자+연금 자산 | 투자·연금 계좌 합 | 전월 대비 증가 |
| **소비 예산 집행률** | 실적 ÷ 월 예산 | 90% 미만 |
| 비상자금 | 즉시 현금성 ÷ 최근 3개월 평균 필수지출 | 6개월 |
| 부채비율 | 총부채 ÷ 총자산 | 40% 이하 |
| DSR | 연간 원리금 ÷ 최근 12개월 소득 | 30% 이하 |
| 목표 달성률 | Σ min(현재, 목표) ÷ Σ 목표 | 지연 0건 |
| 재무자립도 | 월평균 이자·배당 ÷ 월평균 소비 | 장기 100% |

저축·투자·대출 원금상환은 **자본이동**으로 분류해 소비에서 뺍니다. 비정기비(여행·명절·세금·경조사)는 연 예산을 경과 월수만큼 나눠 비교합니다.

## 구성원별 보기

대시보드 `E4`에서 **전체 / 본인 / 배우자 / 공동**을 고르면 손익, 예산 실적, 재무상태표, 투자 비중이 그 구성원 기준으로 바뀝니다.

- 투자 납입 목표는 구성원별로 따로 정합니다 (설정 26~28행). 각자 맡은 몫과 비교합니다.
- **공동** 보기에서는 저축률을 계산하지 않습니다. 공동 계좌는 직접 소득이 거의 없기 때문입니다. DSR은 가계 전체 소득으로 계산합니다.
- 리밸런싱 알림은 가계 전체 포트폴리오 기준(전체 보기)에서만 뜹니다.
- 구성원별 순자산 표는 보기 선택과 관계없이 항상 세 구성원을 모두 보여줍니다.

## 자동화 도구

```bash
pip install openpyxl          # 최초 1회 (이 저장소 루트에서 실행)

# 카드·은행 내역 가져오기: 자동 분류 + 중복 제거
python -m household_finance import 우리집.xlsx 신한카드_10월.csv --member 배우자 --payment 신한카드
python -m household_finance import 우리집.xlsx 국민은행.csv --member 본인 --dry-run   # 미리보기만

# 월말 결산: 지난달 잔액을 복사해 새 달 스냅샷을 만들고 대시보드 기준월 변경
python -m household_finance new-month 우리집.xlsx

# 새 파일 만들기
python -m household_finance build --out 우리집.xlsx --blank
```

- **가져오기**: 카드사·은행 홈페이지에서 받은 내역을 CSV나 .xlsx로 저장해 넣습니다. 국내 금융사에 흔한 cp949 인코딩, 머리말·합계 행, 입금/출금 분리 열을 자동 처리합니다. 열 이름을 못 찾으면 `--date-col 이용일 --desc-col 가맹점명 --amount-col 이용금액`처럼 직접 지정합니다. 취소·환불(음수 금액)은 건너뛰고 따로 보고합니다.
- **자동 분류**: `분류규칙` 시트의 키워드를 위에서부터 비교해 먼저 맞는 규칙으로 분류합니다. 맞는 규칙이 없으면 `미분류`로 들어가고 대시보드에 알림이 뜹니다. 자주 나오는 가맹점은 규칙에 추가해 두면 다음부터 자동으로 분류됩니다.
- **중복 제거**: (일자, 내용, 금액, 구성원)이 같은 거래는 **개수까지** 비교합니다. 같은 날 같은 커피 두 잔도 정상 처리되고, 같은 파일을 두 번 넣어도 안전합니다.
- **구글 시트 시세 연동**: 투자 시트의 현재가 칸에 `=GOOGLEFINANCE("KRX:005930")`처럼 넣으면 시세가 자동으로 반영됩니다.

> 주의: 도구로 저장하면 대시보드 차트 4종은 자동으로 다시 그려지지만, 직접 추가한 차트는 사라질 수 있습니다 (openpyxl 한계). 도구는 구글 시트가 아니라 .xlsx 파일에 작동합니다. 구글 시트로 운영하면 [파일 → 다운로드 → .xlsx] 후 가져오기를 실행하고 다시 업로드하세요. 웹앱을 쓰면 이 과정이 필요 없습니다.
>
> 은행·카드 계좌를 직접 실시간 연동하려면 마이데이터 사업자 인가가 필요해 개인용 도구에서는 바로 구현할 수 없습니다. 그래서 MVP는 내역 파일 가져오기를 자동화했습니다.

## 2단계: 웹앱

스프레드시트와 **같은 계산**을 브라우저에서 씁니다. 부부가 각자 계정으로 로그인해 같은 가계를 보고, 카드 내역 업로드·분류·월말 결산을 화면에서 합니다.

```bash
pip install -r requirements-web.txt          # 최초 1회 (fastapi, uvicorn 등)

# 1단계 엑셀을 그대로 옮겨 시작 (DB가 비어 있을 때만 가져옴)
python -m household_finance serve --db 우리집.db --from-workbook 우리집_자산관리.xlsx
# → 브라우저에서 http://localhost:8000 접속, 처음 화면에서 본인·배우자 계정 생성

# 같은 와이파이의 휴대폰에서도 보려면
python -m household_finance serve --db 우리집.db --host 0.0.0.0
# → 휴대폰에서 http://<이 컴퓨터의 내부 IP>:8000
```

| 메뉴 | 할 일 |
| --- | --- |
| 대시보드 | 기준월·구성원(전체/본인/배우자/공동)을 바꿔 KPI 10개, 알림, 지출 통제·투자 확대·목표·현금흐름 차트 보기 |
| 거래내역 | 월·카테고리·구성원·검색으로 걸러 보기, 카테고리·구성원 바로 수정, **규칙 저장**(같은 키워드의 미분류 거래까지 즉시 재분류), 현금 지출 직접 입력 |
| 내역 가져오기 | 카드·은행 CSV/xlsx 업로드 → 미리보기 → 가져오기 (자동 분류·중복 제거). 1단계 엑셀 올리기, **현재 데이터를 엑셀로 내려받기** |
| 월말 결산 | 달을 고르면 지난달 잔액이 채워진 표 → 바뀐 잔액만 고쳐 저장 → 기준월 변경. 보유 종목 현재가 입력 |
| 예산 | 카테고리별 월/연 예산 설정과 이번 달 실적·상태 |
| 설정 | KPI 기준값, 구성원별 월 투자 납입 목표, 로그인 계정 추가·비밀번호 변경 |

- **계산이 스프레드시트와 같음을 테스트로 보장**합니다: `engine.py`는 엑셀 수식을 옮긴 것이고, `tests/test_household_engine.py`가 샘플 워크북을 LibreOffice로 재계산한 값과 구성원 보기 4종 모두에서 원 단위·문구까지 비교합니다.
- **엑셀과 오갈 수 있습니다**: 웹앱 데이터를 언제든 수식이 살아 있는 .xlsx로 내려받을 수 있고, 엑셀 파일을 올려 웹앱 데이터를 바꿀 수도 있습니다.
- **인터넷 없이 동작**합니다: 화면은 외부 라이브러리·CDN 없이 만들었고, 데이터는 `우리집.db` 파일 하나에 저장됩니다. 이 파일을 정기적으로 백업하세요.
- **보안**: 비밀번호는 scrypt로 해시해 저장하고, 로그인은 HttpOnly·SameSite=Strict 쿠키로 유지합니다. 다만 HTTPS가 아니므로 `--host 0.0.0.0`은 **집 와이파이 안에서만** 쓰고 공유기에서 포트를 외부로 열지 마세요. 밖에서 접속하려면 Tailscale 같은 사설 VPN을 권장합니다.
