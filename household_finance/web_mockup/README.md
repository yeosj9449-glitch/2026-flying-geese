# 웹 대시보드 시안

claude.ai 대시보드 아티팩트로 게시한 웹 시안의 원본입니다. 2단계 웹앱을 만들 때 화면 구성의 기준으로 씁니다.

- `dashboard.html`: 페이지 마크업과 스크립트. 아티팩트 대시보드 런타임의 `dash` API(데이터셋 로딩, `d3` 전역)를 전제로 하므로 단독으로 열면 동작하지 않습니다.
- `data/*.json`: `templates/우리집_자산관리_샘플.xlsx`를 구성원 보기 4종(전체/본인/배우자/공동)으로 각각 재계산해 뽑은 값입니다. 스프레드시트와 같은 수치입니다.

화면 순서: 결산 요약과 구성원 전환 → 핵심 지표 10개 → 알림·구성원별 순자산 → 지출 통제(월별 손익, 예산 대비 실적) → 투자 확대(순자산 추이, 자산배분) → 목표 진척·6개월 현금흐름.
